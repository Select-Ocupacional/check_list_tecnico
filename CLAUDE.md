# Diretrizes do Projeto - Claude Context

## 1. Contexto do Negócio
* **Empresa**: Select Ocupacional
* **Departamento**: Técnico
* **Objetivo**: Desenvolver uma aplicação/sistema de Check-list de Visita Técnica focado em SST (Saúde e Segurança do Trabalho) e Saúde Ocupacional.
* **Propósito**: Digitalizar a coleta de dados em campo, eliminando o uso de papel pelos técnicos durante as vistorias nos clientes.

## 2. Requisitos de Tecnologia (Sugeridos)
* **Interface**: Deve ser totalmente responsiva (Mobile-First), pois os técnicos usarão celulares ou tablets em campo.
* **Idioma**: Todo o código, comentários, documentação e interface devem ser em Português (pt-BR).
* **Segurança**: Garantir a integridade dos dados coletados antes do envio para o banco de dados.

## 3. Diretrizes de Desenvolvimento para a IA
* Priorize códigos limpos, modulares e bem documentados.
* Ao sugerir componentes de formulário, certifique-se de que sejam fáceis de tocar/clicar em telas pequenas.
* Implemente validações robustas para evitar campos obrigatórios em branco.
